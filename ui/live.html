    PAD 표본 수집

    카메라를 보며 표본을 수집해요. 원본 영상은 저장하지 않아요.

    얼굴이나 사진을 화면에 맞춰 주세요.
    카메라와 50~80cm 거리를 두면 좋아요.

    수집 설정

    실제 사람·인쇄 사진·화면 재생의 깊이 형상과 적외선 수치를 비교해요. 버튼을 누른 촬영의 숫자만 기록하며, 원본 영상과 얼굴 사진은 저장하지 않아요. 측정 완료는 실제 사람 판정이나 인증 승인이 아니에요.

    얼굴 등록 여부와 관계없이 활성 계정을 선택할 수 있어요.

    표본 수집·생체정보 처리 안내

    정면에서 5개 프레임의 수치를 수집합니다. 측정이 어려운 프레임도 제외하지 않아요.

    같은 사람과 같은 공격 매체는 한 용도에만 사용해 주세요. 평가용은 학습·보정에 사용하지 않아요.

    이름 대신 subject-001처럼 익명 코드를 입력해 주세요. 공백은 사용할 수 없어요.

    인쇄 사진은 print-001, 휴대폰은 phone-001처럼 구분해 주세요. 공백은 사용할 수 없어요.

    지금은 5프레임 진단이에요. 실제 인증·등록 촬영 시험으로 인정되지 않아요. 위의 ‘인증 촬영 시험’ 또는 ‘실제 사람 등록 시험’을 선택해 주세요.

    계정과 수집 동의를 확인해 주세요.
