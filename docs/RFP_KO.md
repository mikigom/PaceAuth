# 1. 사업 범위 및 설계 가정
고객의 동의와 계정 소유 확인을 거쳐 회전 안내로 얼굴을 등록하고, 이후 ID 입력 없이 1:N으로 고객을 식별·인증한다. 전용 단말, 중앙 서버, 관리 화면, 운영·보안 검증을 포함한다.
규모 가정: 최대 100만 명, 고객당 기본 4개 템플릿, 피크 100 인증 세션/초. 초기 촬영 거리 40~80cm의 협조적 사용을 전제로 하며, 단말 수·조명 범위·예산은 발주 시 확정한다.
# 2. 기준 모델 및 채택 조건

| 기능 | 우선 평가 후보 | 적용 조건 |
|---|---|---|
| 회전 안내 | 6DRepNet360 [1] | 일반 / Full Rotation을 실제 등록 범위에서 비교 |
| 얼굴 검출 | SCRFD-34G [2] | 동일 해상도·지연 조건에서 동급 이상 대안 허용 |
| 정밀 랜드마크 | FaRL ViT-B, 448px [3] | 인식용 크롭은 인식 모델의 공식 정렬과 호환 |
| 주 얼굴 인식 | InsightFace ViT-L / WebFace42M [4] | KP-RPE ViT-B + AdaFace / WebFace12M과 비교 [5] |
| 위조 방어 | RGB·Depth·IR 결합 PAD | 실제 센서 시퀀스로 개발·검증; 독립 시험 필수 [6] |

정확한 가중치·해시·전처리·재현 성적을 제출한다. InsightFace 배포 모델은 비상업 연구용 제한이 있으며, CVLFace 모델은 학습 데이터의 라이선스를 따른다. 상용 허가 또는 적법한 자체 학습이 채택 전제다. [4][5]

# 4. 인수 목표 초안
다음 수치는 달성 보장이 아닌 발주 목표다. 공급사는 충족 여부·시험 규모·비용을 제시하며, 최종 환경·공격 범위·한계값을 계약에 고정한다.

| 항목 | 목표 | 시험 및 판정 조건 |
|---|---|---|
| 1:N 정확도 | FPIR ≤ 10⁻⁶ 동일 임계값에서 FNIR ≤ 1% | 최대 갤러리에서 평가. 95% 신뢰구간 제출; 등록 고객의 타인 오식별도 별도 집계 |
| 지연·처리량 | 100 인증 세션/초 p95 ≤ 1.5초 / p99 ≤ 2.5초 | 인증 첫 프레임 수집부터 최종 응답까지. 네트워크·PAD·검색 포함, 등록 시간 제외 |
| 등록 품질 | 등록 성공률 ≥ 99% 등록 시간 p95 ≤ 20초 | 합의한 사용자·환경 조건에서 측정. 실패·중도 포기·재시도도 함께 보고 |
| PAD | ISO/IEC 30107-3 기반 독립 시험 [6] | 사진·영상·가면별 APCER/BPCER 및 전체 공격 성공률·비응답률 보고. 한계값 별도 고정 |
| 가용성·복구 | 월 99.95% RTO ≤ 15분 | 단일 노드 장애 시 승인 완료된 등록·철회 RPO=0. 복구 중 승인 조건 완화 금지 |

용어: FPIR=미등록자 검색의 오인식률, FNIR=등록자의 정답을 찾지 못하는 비율. 모델 지표와 촬영·PAD 실패를 포함한 전체 세션 결과를 구분한다. 무오류 시험만으로 FPIR 10⁻⁶의 95% 상한을 입증하려면 약 300만 회의 독립 검색이 필요하며, 인접 프레임 반복으로 대체하지 않는다.
# 5. 벤치마크 및 검증 계획

| 평가 영역 | 권장 평가 자료 / 제출 결과 |
|---|---|
| 회전·검출·정렬 | BIWI, AFLW2000-3D, WIDER FACE, WFLW + 실제 등록 영상. 각도 오차·검출 누락·랜드마크 오차·잘못된 등록 완료율. [1][2][7][8] |
| 얼굴 식별 | IJB-C(적법한 접근 확보 시), CFP-FP, CPLFW, AgeDB-30 및 동의 기반 현장 1:N. 등록·인증은 다른 날짜·세션으로 분리. |
| RGB·Depth·IR PAD | CeFA, WMCA의 RGB·Depth·IR 채널 및 자체 센서 공격 자료. 학습에 없던 장소·센서·공격 유형을 별도 평가. [10][11] |

학습·검증·최종 시험 인물을 분리하고, 최종 시험 전에 모델·임계값을 고정한다. NIST의 IJB 배포는 2023년 3월 14일 중단되었으므로 허가된 확보 경로와 대체 시험을 제안한다. 모든 데이터셋의 평가·상용 이용 조건을 확인한다. [9]
